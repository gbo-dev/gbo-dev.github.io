## 🌻 gbo-dev.github.io

Profile website made with Hugo.

## Usage
1. Clone repository and install Hugo. If you want to use Sass, make sure to install appropriate Hugo edition.
2. Run live-reloadable server with `hugo server --disableFastRender` (flag for full rebuilds on change)
3. Add markdown files in `/content` or run `hugo new path/filename.md` to create a new markdown file with prefilled header in the specified `path`.

To apply persistent changes to a theme, mirror the file name and directory structure of the theme.
